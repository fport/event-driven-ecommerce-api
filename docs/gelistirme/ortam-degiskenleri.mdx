# Ortam Degiskenleri

Her mikro servis kendine ozgu ortam degiskenlerine ihtiyac duyar. Bu sayfa tum servislerdeki degiskenleri, varsayilan degerlerini ve zorunluluk durumlarini listelemektedir.

<Warning>
  Production (uretim) ortaminda `AUTH_SECRET`, veritabani sifreleri ve OAuth client secret degerleri **mutlaka** degistirilmelidir. Varsayilan degerleri uretim ortaminda kullanmak ciddi guvenlik aciklarina yol acar.
</Warning>

## Ortak Degiskenler

Asagidaki degiskenler tum servislerde ortaktir:

| Degisken | Zorunlu | Varsayilan | Aciklama |
|----------|---------|------------|----------|
| `PORT` | Evet | Servise gore degisir | Servisin dinledigi port numarasi |
| `NODE_ENV` | Hayir | `development` | Calisma ortami (`development`, `production`) |
| `APM_SERVER_URL` | Hayir | `http://apm-server:8200` | Elastic APM (Application Performance Monitoring) sunucu adresi |
| `APM_SERVICE_NAME` | Hayir | - | APM'de gosterilecek servis adi |

## Ornek `.env` Dosyasi

Yerel gelistirme ortami icin kullanabileceginiz ornek `.env` dosyasi:

```bash .env
# Genel
NODE_ENV=development

# PostgreSQL
DATABASE_URL=postgres://postgres:postgres@localhost:5432/orders
DATABASE_REPLICA_URL=postgres://postgres:postgres@localhost:5433/orders

# Redis
REDIS_URL=redis://localhost:6379

# RabbitMQ
RABBITMQ_URL=amqp://guest:guest@localhost:5672

# MongoDB
MONGODB_URL=mongodb://localhost:27017/notifications

# Elasticsearch
ELASTICSEARCH_URL=http://localhost:9200

# APM
APM_SERVER_URL=http://localhost:8200

# Auth
AUTH_SECRET=super-secret-key-change-in-production
BASE_URL=http://localhost:3000

# OAuth (opsiyonel)
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
```

## Docker Compose Ortaminda Degiskenler

Docker Compose kullaniminda servisler birbirine container adi uzerinden erisir. Bu nedenle `localhost` yerine servis adlari kullanilir:

```yaml
# docker-compose.yml icinden ornek
environment:
  - DATABASE_URL=postgres://postgres:postgres@postgres:5432/orders
  - REDIS_URL=redis://redis:6379
  - RABBITMQ_URL=amqp://guest:guest@rabbitmq:5672
  - MONGODB_URL=mongodb://mongo:27017/notifications
  - ELASTICSEARCH_URL=http://elasticsearch:9200
```

<Warning>
  Yerel gelistirme ile Docker Compose ortaminda host isimleri farklidir. Yerel gelistirmede `localhost`, Docker Compose'da ise container servis adlari (ornegin `postgres`, `redis`, `rabbitmq`) kullanilir.
</Warning>

## Uretim Ortami Icin Kontrol Listesi

Uretim ortamina gecmeden once asagidaki degiskenlerin guncellenmesi **zorunludur**:

| Degisken | Neden |
|----------|-------|
| `AUTH_SECRET` | Varsayilan deger (`super-secret-key-change-in-production`) guvensizdir |
| `POSTGRES_PASSWORD` | Varsayilan `postgres` sifresi kabul edilemez |
| `RABBITMQ_DEFAULT_USER/PASS` | Varsayilan `guest/guest` yalnizca gelistirme icindir |
| `GF_SECURITY_ADMIN_PASSWORD` | Grafana varsayilan `admin` sifresi degistirilmelidir |
| `GITHUB_CLIENT_SECRET` | Production OAuth uygulamasinin gercek secret'i kullanilmalidir |
| `GOOGLE_CLIENT_SECRET` | Production OAuth uygulamasinin gercek secret'i kullanilmalidir |
